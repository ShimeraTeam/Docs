# Shimera Documentation

Sources of the official [Shimera](https://github.com/ShimeraTeam/Shimera)
documentation (user and contributor guides, in English and French), built with
VitePress and published at <https://shimerateam.github.io/Docs/>.

## Run locally

```bash
npm install
npm run dev
```
