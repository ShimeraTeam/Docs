# Contributing to the Shimera Documentation

Thanks for helping improve the Shimera documentation. Fixes, clarifications,
new examples and translations are all welcome.

The general contribution rules (branch names, Conventional Commits, pull request
format) are the same as for the library: see the
[Shimera CONTRIBUTING.md](https://github.com/ShimeraTeam/Shimera/blob/main/CONTRIBUTING.md).

## Writing guidelines

- Keep the English (`docs/`) and French (`docs/fr/`) pages in sync when a change
  applies to both.
- Code examples must compile against the current Shimera API.
- Only add images, GIFs or diagrams that you created yourself (for example a
  capture of a Shimera example). Do not add third-party images, even with
  credit, unless their license is compatible with CC BY 4.0 **and** you say so in
  the pull request.
